# Настройка дисплея для мультимониторных систем

## Важно

В Linux/X11 есть разница между:
- **X-серверы (displays)**: `:0.0`, `:1.0` - это разные X-серверы (обычно один на систему)
- **Мониторы (monitors)**: физические мониторы, подключенные к одному X-серверу

`DISPLAY_NUMBER` в `.env` относится к **X-серверам**, а не к физическим мониторам.

## Использование DISPLAY_NUMBER

### Для разных X-серверов:
```env
DISPLAY_NUMBER=0  # X-сервер :0.0 (обычно основной)
DISPLAY_NUMBER=1  # X-сервер :1.0 (если запущен второй X-сервер)
```

### Для разных мониторов на одном X-сервере:

Если у вас несколько мониторов на одном X-сервере (обычный случай), используйте `DISPLAY_NUMBER=0` и настройте позиционирование окна через другие методы.

## Проверка доступных дисплеев

Запустите игру и проверьте вывод в консоли:
```
[Main] Setting DISPLAY to: :1.0
[Game] Number of displays detected: 2
[Game] Desktop sizes: [(1920, 1080), (1920, 1080)]
```

## Альтернативные методы

Если `DISPLAY_NUMBER` не работает для переключения между мониторами, можно:

1. Использовать `xrandr` для получения информации о мониторах
2. Позиционировать окно программно после создания
3. Использовать оконный менеджер для управления окнами

## Отладка

Если окно не появляется на нужном мониторе:

1. Проверьте значение `DISPLAY` в консоли при запуске
2. Убедитесь, что X-сервер с указанным номером запущен
3. Проверьте логи в консоли для диагностики
