# Новогодняя Аркадная Игра с Компьютерным Зрением

## Концепция игры

Интерактивная аркадная игра, проецируемая на белую тканевую поверхность, где игроки должны выбивать новогодних персонажей, бросая реальные снежные шарики из пенопласта.

## Технические компоненты

### 1. Калибровка и коррекция перспективы
- **Aruco метки** в четырех углах игрового поля
- Трапециевидное транспонирование для коррекции искажений проекции
- Автоматическое определение границ игрового окна
- Адаптация к наклону поверхности

### 2. Обнаружение снежного шарика
- Компьютерное зрение для отслеживания пенопластового шарика
- Определение размера/площади шарика
- Определение момента столкновения (когда площадь становится минимальной)
- Вычисление координат центра попадания
- Проверка коллизии с фигурками на экране

## Игровые механики

### Персонажи (Enemies)
1. **Снеговик** (базовый враг)
   - Движется слева направо на разных высотах
   - Медленная скорость
   - Легко убивается

2. **Гринч** (средний враг)
   - Средняя скорость
   - Больше здоровья, требует 2 попадания

3. **Дед Мороз** (редкий враг)
   - Быстрый
   - Дает больше очков
   - Может давать артефакты

4. **Эльф** (малый враг)
   - Маленький размер
   - Быстрый
   - Низкий уровень здоровья

5. **Рудольф (Олень)** (босс-враг)
   - Большой размер
   - Медленный
   - Много здоровья
   - Появляется редко

### Артефакты и способности

1. **Артефакт Снеговика** - "Тройной выстрел"
   - При убийстве специального снеговика с артефактом
   - При следующем попадании появляются 3 виртуальных шара
   - Шары разлетаются в разные стороны, нанося урон всем врагам на пути

2. **Артефакт Гринча** - "Замедление времени"
   - Все враги замедляются на 10 секунд
   - Дает время для прицеливания

3. **Артефакт Деда Мороза** - "Метеоритный дождь"
   - Автоматически бросает несколько виртуальных шаров в случайных точках
   - Убивает всех врагов на экране

4. **Артефакт Эльфа** - "Множитель очков"
   - Увеличивает полученные очки в 2 раза на 30 секунд

5. **Артефакт Рудольфа** - "Мощный удар"
   - Следующий бросок наносит урон в радиусе вокруг точки попадания

### Система очков
- Снеговик: 10 очков
- Гринч: 25 очков
- Дед Мороз: 50 очков
- Эльф: 15 очков
- Рудольф: 100 очков
- Артефакты дают бонусные очки

### Система здоровья врагов
- Базовые враги: 1 HP
- Средние враги: 2 HP
- Боссы: 3-5 HP

### Волны врагов
- Враги появляются волнами
- С каждой волной увеличивается количество и скорость врагов
- Специальные враги с артефактами появляются периодически

## Визуальный дизайн

### Стиль
- Яркие новогодние цвета (красный, зеленый, белый, золотой)
- Снежинки на фоне
- Новогодняя музыка (опционально)
- Праздничные эффекты при убийстве врагов

### Анимации
- Анимация движения врагов (спрайты или простая графика)
- Анимация падения/исчезновения при убийстве
- Эффекты попадания снежного шара
- Визуализация артефактов и их эффектов

## Этапы разработки

### Фаза 1: Базовая игра (текущая)
- ✅ Описание идеи
- 🔄 Простая версия с кликом мыши по персонажам
- Персонажи движутся слева направо
- Клик по персонажу засчитывает убийство
- Базовый интерфейс с очками

### Фаза 2: Компьютерное зрение
- Интеграция Aruco меток для калибровки
- Трапециевидное транспонирование
- Обнаружение снежного шарика
- Определение попаданий по координатам

### Фаза 3: Расширенные механики
- Система здоровья врагов
- Артефакты и способности
- Волны врагов
- Улучшенная графика и анимации

### Фаза 4: Полировка
- Звуковые эффекты
- Музыка
- Меню и настройки
- Сохранение рекордов

## Технологии

- **Python** - основной язык
- **OpenCV** - компьютерное зрение, Aruco, обнаружение объектов
- **NumPy** - математические операции, матрицы для трансформаций
- **Pygame** или **Tkinter** - игровой движок/отображение
- **АрUco markers** - библиотека для распознавания маркеров
